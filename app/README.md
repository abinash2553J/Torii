# Fest Check-in

The React, TypeScript and Vite application for Fest Check-in.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to type-check and create the production build.

Product requirements and implementation constraints are in
[`../fest-check-in-agent-docs/README.md`](../fest-check-in-agent-docs/README.md).

The app is currently a branded shell. Authentication, event setup,
ticketing and check-in are not implemented yet.
